채점 보안 강화 적용

먼저 SECURITY_KO.md를 확인하세요.
Docker Desktop(Linux 컨테이너) 또는 Docker Engine 실행 후 backend 폴더에서:

docker build --pull -t learning-path-judge:1 sandbox
python tools/check_judge.py

검사 6개 통과 후 FastAPI를 기존 방식으로 실행합니다.
Docker가 없거나 꺼져 있으면 예제/제출 실행은 차단됩니다.
이번 보안 수정만 적용할 때 추가 SQL 변경은 없습니다.

아래는 이전 문제은행을 아직 적용하지 않은 경우의 안내입니다.

문제·테스트케이스 보강 버전 적용

1. 기존 백엔드를 종료합니다.
2. MariaDB에서 기존 DB를 선택하고 backend/sql/00_check_existing.sql을 확인합니다.
3. backend/sql/01_strengthen_problem_bank.sql 전체를 실행합니다.
   사용자/제출 기록을 지우는 기존 DROP SQL을 다시 실행하지 마세요.
4. 새 프로젝트의 백엔드를 기존 방식으로 다시 실행합니다.
5. 러닝패스 폴더에서 flutter pub get 후 앱을 다시 실행합니다.

전체 소스가 러닝패스 폴더 하나에 들어 있습니다.
앱만 교체하면 문제/테스트는 늘어나지 않으므로 SQL 적용이 필요합니다.
기본 입력 코드 직접 설정은 제거했고 자동 입력 코드 제공은 유지했습니다.
오답 복습 등 기존 기능은 유지합니다.
